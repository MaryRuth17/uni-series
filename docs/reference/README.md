# Reference images (local only)

Art reference from the game owner. **Never ship these in the game or trace them** (SPEC-pup-lagoon.md §15).
The image files are gitignored because this repo is public and we don't hold the rights to every photo. They live
only in the owner's main checkout (`uni-series/docs/reference/`). Agents in other worktrees read them from there.

| File | What it shows | Used by |
|---|---|---|
| `ubelt-map.webp` | U-Belt + Sta. Mesa map, campuses in gold, LRT-2 dashed purple, Pasig River (OpenStreetMap data) | SPEC-homepage.md §4 campus map |
| `lagoon-plaza.png` | Red-brick circular plaza, white curved bands, hexagonal planter with the big red letter sign, trees, pergola | SPEC-pup-lagoon.md §3 zone A |
| `lagoon-stall-row.png` | White concrete-block stall row, navy steel awning on cables, accordion shutters, red/yellow balloon pairs, garden bed with white flowers | §3 zone D |
| `kiosk-display-case.png` | Glass display case: steel trays, handwritten labels (Chicken Teriyaki, Chopsuey, Curry, Adobo, Liempo Inihaw, BBQ, Tonkatsu), fluorescent tube | §3 zone E, item cards |
| `kiosk-front.png` | Red kiosk front, "70.00 FREE DRINKS" price sign, photo menu banner, TOYO jug, bread display | §3 zone E. It shows a **real stall's name**: never copy it (§15) |

If the owner confirms they own a photo (or it has a licence that allows it), it can be committed by adding a `!` exception to `.gitignore`.
